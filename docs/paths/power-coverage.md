# 专题链：功率控制与覆盖专题

功率控制与覆盖优化是无线网优岗的看家本领，也是区分"会算数"和"会落地"的分水岭。面试官沿这条链追问时，先看你能不能写出上行功控公式、说清 PHR 的作用；再看你懂不懂链路预算里每个余量为什么存在；最后落到真实投诉场景——上下行不平衡怎么判断、SUL 为什么能救覆盖、下倾角该怎么算。这条链的特点是"公式少但个个必考，案例多但环环相扣"：功控公式是理论起点，链路预算是规划工具，投诉案例是验收标准。学完你应能把"dB 意义上的正确"讲成"现场意义上的可用"。

## 链路检查点

学完这条链，试着不看答案回答这三个递进问题，能全程串讲才算过关：

1. **基础**：写出上行 PUSCH 功控公式，说明 P0、alpha、闭环 TPC 各自的作用；PHR 有哪几类、什么时候触发？
2. **进阶**：链路预算中穿透损耗与阴影余量分别对哪个概率指标负责？C-band 组网时上下行不平衡的根因是什么，SUL 是从哪条链路上解决它的？
3. **综合**：某高层住宅用户投诉"室外信号满格、室内刷视频卡顿"，请按"路测定位 → 链路预算逐项核对（穿透/阴影/上下行）→ 参数与射频调整（功控/下倾角/SUL）"给出完整排查与优化方案，并说明每一步用什么数据支撑决策。

学完这条链，可以继续 [NTN 入门到实战](/paths/ntn-deep-dive)——把地面链路预算的功力迁移到卫星场景，看看路径损耗放大几个数量级后功控与覆盖要怎么重来一遍。
