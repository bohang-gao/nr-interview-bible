# 专题链：QoS 与会话专题

QoS 是 5G 面试里最容易"背了但串不起来"的板块：5QI 背得出、SDAP 说得清，一旦被问"一条视频业务从切片选择到空口承载经过哪几层"，很多人就开始卡壳。这条链就按数据面的真实顺序编排：先看 SDAP 怎么把 QoS flow 映射到 DRB，再理清 QoS flow/DRB/PDU session 三层归属；然后过 5QI 的标准化取值与 GBR 分类，转到控制面的切片选择与会话建立信令，最后用切片 SLA 收尾——技术参数如何兑现成商业承诺。学完你应能双向回答："给业务描述，我配得出承载链"和"给信令流程，我指得出 QoS 在哪一步被决定"。

## 链路检查点

学完这条链，试着不看答案回答这三个递进问题，能全程串讲才算过关：

1. **基础**：QoS flow、DRB、PDU session 三层各自由哪个网元/协议层管理？5QI 的 GBR 与非 GBR 典型取值各举一例？
2. **进阶**：一条 QoS flow 到 DRB 的映射由谁决定（显式 vs reflective）？切片选择时 NSSF 与 AMF 的分工边界在哪，PDU 会话建立信令里 QoS 参数在哪一步被下发？
3. **综合**：某企业要签"园区内视频回传时延 <20ms、可用性 99.9%"的切片 SLA，请给出"切片选择 → 会话建立 → 5QI/GBR 参数落地 → SDAP/DRB 映射 → SLA 验收指标"的端到端配置叙事，并说明每一步用什么 KPI 验证兑现。

学完这条链，可以回到 [安全与密钥专题](/paths/security-keys) 补上 PDCP 往下的安全视角——DRB 上既跑着 QoS 映射也套着加密保护，两条链合看才是完整的空口承载叙事。
