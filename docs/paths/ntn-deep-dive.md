# 专题链：NTN 入门到实战

NTN 是 R17 以来增长最快的面试新考点：懂的人还不多，但卫星通信岗位几乎必问，常规岗位也开始拿它当加分题。这条链按"认知 → 差异 → 对策 → 实战"四层编排：先用两题建立 NTN 是什么、弯管与再生两种架构怎么选；再用一题量化多普勒与传播时延的量级——这是 NTN 一切特殊设计的根源；接着进入全链最硬核的三步，公共 TA、K-offset 与上行定时预补偿，看协议怎么把"几百毫秒的时延"驯服进既有 NR 框架；最后走到随机接入、移动性与链路预算的落地题。学完你应能把"卫星在天上动"讲成"参数在协议里怎么改"。

## 链路检查点

学完这条链，试着不看答案回答这三个递进问题，能全程串讲才算过关：

1. **基础**：NTN 为什么不能直接复用地面 NR 的时序框架？弯管与再生架构下，基站功能分别放在哪里？
2. **进阶**：LEO 600km 场景下单程传播时延与多普勒频移各是什么量级？说明 ta-Common、UE 自主 TA、K-offset 三者各补哪一段时延/频偏，UE 上行预补偿的完整计算流程是什么？
3. **综合**：某运营商要在偏远山区用 LEO NTN 做补盲，请给出"链路预算（覆盖半径/余量）→ 时序参数（K-offset/TA 方案）→ 接入与切换策略（星历辅助/无距离依赖）"的完整设计叙事，并指出每一步与地面组网的关键差异。

学完这条链，可以回到 [功率控制与覆盖专题](/paths/power-coverage) 复习地面链路预算的通用方法——NTN 的预算只是把路径损耗与多普勒推到极端量级，方法论一脉相承。
