# 专题链：移动性与切换专题

切换是连接态移动性的核心，也是掉话类 KPI 的第一嫌疑人。面试官爱问它，因为切换链条天然带层次：从测量配置怎么下发、事件怎么触发，到 Xn/NG 两条信令路径怎么走，再到 CHO 这类增强机制为什么出现，最后落到"切换失败怎么定位"——每一层都能单独追问，串起来又能考察端到端的信令把握。这条链学完，你应能从"测量 Gap 是什么"一路讲到"KPI 口径与失败归因"，覆盖研发与网优两个岗位的常见问法。

## 链路检查点

学完这条链，试着不看答案回答这三个递进问题，能全程串讲才算过关：

1. **基础**：测量配置三要素分别装什么？A1/A2/A3/B1 各典型用在哪个流程？
2. **进阶**：完整描述一次 Xn 切换的三阶段信令与数据前转，并说明什么条件下必须改走 NG 切换、代价是什么？
3. **综合**：某路段切换成功率偏低，请给出"测量配置 → 事件参数（CIO/迟滞）→ 信令路径（Xn/NG）→ 失败段归因"的完整排查框架，并说明 CHO 适合插在哪个环节解决问题。

学完这条链，可以回到 [随机接入专题](/paths/ra-random-access) 补上"切换失败后重建/重接"的接入侧细节，两条链合起来就是完整的"连接建立与保持"叙事。
