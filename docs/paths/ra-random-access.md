# 专题链：随机接入专题

随机接入是 UE 从"看不见网络"到"被网络调度"的第一跳，也是接入类 KPI 与大量现场问题的发源地。面试官爱问它，是因为这一条链上能同时考察物理层（PRACH 资源与序列）、信令流程（msg1–msg4）、异常处理（竞争失败与接入失败定位）和网优落地（根序列规划、KPI 口径）——一道题就能分出"背过流程"和"真处理过问题"的候选人。沿这条链学完，你应能从"为什么触发"讲到"画得出流程"，再讲到"接不通时从哪查起"。

## 链路检查点

学完这条链，试着不看答案回答这三个递进问题，能全程串讲才算过关：

1. **基础**：RA 的触发场景有哪些？哪些走 CBRA、哪些必须走 CFRA？
2. **进阶**：从 PRACH 格式与 RO 配置出发，说明小区接入容量由哪些因素决定？两步 RA 省掉的两步交互分别换来了什么、付出了什么？
3. **综合**：某小区接入成功率突然下降，请按"资源层（RO/根序列）→ 消息层（msg1–msg4 在哪一步失败）→ KPI 口径"完整给出排查框架，并说明每一步看什么指标。

学完这条链，可以继续 [移动性与切换专题](/paths/mobility-handover)——接入是静态起点，切换是动态延续，两者共同构成"连接建立与保持"的完整叙事。
