# 专题链：安全与密钥专题

安全与密钥是 5G 面试里"看似小众、实则必问"的一块——因为它最能区分背过八股和真理解协议的人。这条链的编排刻意做成"先树干后枝叶"：先建立从 K 推导出 KgNB/KAMF 的整棵密钥树，再看 AS/NAS 两级安全分别在什么时机、由谁激活；然后追问切换时密钥怎么刷新（水平/垂直推导防的是什么），最后落回 PDCP 层——加密保什么、完整性保什么、哪些字段永远不加密。学完这条链，你应能回答"为什么密钥要分层推导"这类为什么题，也能画得出安全激活的时序，而不是只背得出算法编号。

## 链路检查点

学完这条链，试着不看答案回答这三个递进问题，能全程串讲才算过关：

1. **基础**：画出从 K 到各层密钥的推导树，说明 KgNB 与 KAMF 的用途分工；AS 与 NAS 安全分别在什么时机、由哪条消息激活？
2. **进阶**：切换时密钥更新有水平与垂直两种推导，各自的输入是什么？为什么刷新 KgNB 能防止"前向安全"被攻破？PDCP 加密与完整性保护分别覆盖哪些数据、明确不保护什么？
3. **综合**：某基站升级后用户投诉"切换后偶发掉话，重建集中在切换完成瞬间"，请从密钥更新链路出发给出排查框架（切换类型 → KgNB 推导方式 → PDCP 重建参数），并说明每一步用什么信令或计数器验证。

学完这条链，可以继续 [QoS 与会话专题](/paths/qos-session)——安全保证"说得话不被偷听"，QoS 决定"说得话走哪条车道"，两者共同构成 PDCP 往上的完整用户体验叙事。
