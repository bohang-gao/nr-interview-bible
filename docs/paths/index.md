# 专题学习链总览

逐章刷题是"纵向积累"，专题链是"横向串联"——把散在各章的同一主题题目按面试官的追问顺序重新编排，帮你从"知道每道题的答案"升级到"讲得出一条完整叙事"。每条链由导语（为什么面试官爱问）、编号步骤卡（题目链接 + 一句学习要点）和三个递进自测检查点（基础 → 进阶 → 综合）构成；建议先顺着步骤通读，再合上答案自查检查点，能全程串讲才算过关。下面是全部 6 条专题链，按"接入 → 移动性 → 功率覆盖 → 安全 → QoS → NTN"的难度与依赖关系排列，可按岗位需要选链深修。

## 建议刷法

- **按岗选链**：网优岗优先「功率控制与覆盖」「移动性与切换」；协议/研发岗优先「随机接入」「安全与密钥」；核心网与行业方案岗优先「QoS 与会话」；卫星方向直接主攻「NTN 入门到实战」。
- **链间组合**：「随机接入 → 移动性与切换」构成完整的连接建立与保持叙事；「安全与密钥 ↔ QoS 与会话」在 PDCP 层互为表里；「功率控制与覆盖 → NTN」是从地面到卫星的量级跃迁。
- **验收标准**：每条链末尾的三个检查点不看答案能依次串讲，才算这条链毕业——卡在哪一问，就回到对应步骤卡重学。
