### ch02-q043-prach-ro-calculation.md — ❌

- **断言**：「长格式（839 点序列）：以 1.25 kHz SCS 计占用 864 子载波（对应 **72 个 15 kHz 的 RB** 量级）」
- **问题**：864 × 1.25 kHz = 1.08 MHz，折合 15 kHz PRB（180 kHz/PRB）只有 **6 个 RB**；"72 个 RB"@15 kHz = 12.96 MHz，差 12 倍。864 子载波@1.25 kHz 对应的是 72 个 15 kHz **子载波**（72 × 15 kHz = 1.08 MHz），疑把"子载波"误写成"RB"。
- **依据**：TS 38.211 V17.3.0 §6.3.3.2（ΔfRA = 1.25 kHz 时 PRACH 占 1.08 MHz ≈ 6 个 15 kHz PRB）。
- **建议改法**：「以 1.25 kHz SCS 计占用 864 子载波（1.08 MHz，对应 6 个 15 kHz PRB / 72 个 15 kHz 子载波）」。
- 其余断言核对无误：短格式 139 点占 12 RB/144 子载波、每根序列前导数 ⌊L/N_CS⌋（38.211 §6.3.3.1：64 前导按循环移位+逻辑根序列顺序枚举，单根不够再取连续逻辑索引）、msg1-FDM 1/2/4/8、PRACH 周期、⌈64/13⌉=5 根序列、N_CS 与小区半径关系。

### ch02-q045-timing-advance.md — ❌

- **断言 1**：「RAR 中 TA 初值…粒度 16×Tc」「TA 命令 6 bit，粒度同为 16×Tc 量级」
  - **问题**：漏了 ×64/2^μ。规范公式为 NTA = TA·16·64/2^μ·Tc，即每步 **16×64×Tc/2^μ**（15 kHz 下 ≈0.52 μs/步，30 kHz 下 ≈0.26 μs/步）。依据 TS 38.213 V17.3.0 §4.2（TA = 0..3846，NTA = TA·16·64/2^μ）。
- **断言 2**：「6 bit…索引 0~63 对应 0 到 +63 步进（63 也用作绝对切换/重置语义）」
  - **问题**：错。相对 TA 命令为 **NTA_new = NTA_old + (TA−31)·16·64/2^μ·Tc**（TA = 0..63），偏移二进制、居中于 31，范围 −31~+32 步；TA=31 表示"不变"，无 "TA=63 重置" 语义。且该说法与文中"可正可负"自相矛盾。
- **断言 3**：「单次调整幅度约 ±4 μs 量级以内」→ 低估 2~4 倍：μ=0 时最大 ±32 × 0.52 μs ≈ ±16.7 μs；μ=1 时 ≈ ±8.3 μs。
- **断言 4**（手算感觉）：「半径 1 km → 往返时延约 6.7 μs → TA 约 **13×16×Tc** 量级」「半径每增 1 km 增大约 13 个 16×Tc 步进」
  - **问题**：漏 ×64。6.7 μs ≈ 13 个 **16×64×Tc** 步进（15 kHz 下 13 × 0.5218 μs = 6.78 μs ✓）。
- **断言 5**：「RAR TA 覆盖约几百微秒」→ 偏小：TA 最大 3846，15 kHz 下 ≈2.0 ms、30 kHz 下 ≈1.0 ms；"对应百公里级"（≈150~300 km）结论成立。
- 核对无误：Tc ≈ 0.509 ns（1/196.608e6 ✓）；RAR 字段 12 bit（TA=0..3846）；"UE 移动 1 m，TA 变化 6.6×2×Tc ≈ 13.2 Tc"（2 m 往返路径 / c ✓）。
- **建议改法**：全文把 TA 粒度统一改为「16×64×Tc/2^μ」；6 bit 命令改为「TA−31，范围 −31~+32 步，TA=31 不变」；手算换算改为「每 km 往返 ≈ 13 个 16×64×Tc 步进（15 kHz）」；RAR 覆盖改为「15 kHz 下约 2 ms」。

### ch02-q048-rb-re-bandwidth-calc.md — ❌

- **断言 1**（换算表）：「20 MHz @15 kHz → **51 PRB**（0 MHz 段内）」
  - **问题**：20 MHz @15 kHz 协议值为 **106 PRB**，与本文件自己的手算例 2（"20 MHz @15 kHz…协议取 106 PRB"）直接矛盾；"（0 MHz 段内）"为乱码残留。表头「20 MHz（48 PRB 量级）」亦不妥。
  - **依据**：TS 38.101-1 Table 5.3.2-1（20M/15k = 106，20M/30k = 51）。
- **断言 2**（换算表）：「120 kHz → **264 PRB（FR2 100 MHz 上下）**」
  - **问题**：264×12×120 kHz = 380 MHz，物理上装不进 100 MHz 信道。100 MHz @120 kHz（FR2）= **66 PRB**（66×12×120k = 95.04 MHz）；264 PRB 实为 **200 MHz@60 kHz** 或 **400 MHz@120 kHz（FR2-2，R17）** 之值。
  - **依据**：TS 38.101-2 Table 5.3.2-2 + 带宽核算。
- **建议改法**：15 kHz 行 20 MHz 格改「106 PRB」；120 kHz 行改「100 MHz → 66 PRB（FR2）；264 PRB 对应 200M@60k / 400M@120k（FR2-2）」；表头改「20 MHz（106 PRB @15k / 51 PRB @30k）」。
- 核对无误：273 PRB @100M/30k（98.28 MHz ✓）、106 @40M/30k（38.16 MHz ✓）、135 @100M/60k（97.2 MHz ✓）、SSB 240 子载波 = 20 PRB（3.6/7.2 MHz ✓）、FR1 开销 DL 14% / UL 18%（TS 38.214）。
- **⚠️ 附注**：峰值手算例「1.6~1.9 Gbps」隐含 TDD 上下行配比假设；纯 FDD 理论 ≈2.3 Gbps（91.7M RE/s × 8 bit × 4 流 × 0.9 码率 × 0.86 开销），建议注明前提。

### ch02-q050-ssb-vs-data-coverage.md — ⚠️

- **断言**：「发送资源：固定周期，含 **1/2 个符号**中的 PSS/SSS/PBCH」
  - **问题**：表述不通。SSB 为 **4 个 OFDM 符号 × 240 子载波**（PSS 符号 0，PBCH/DMRS 符号 1、3，SSS+PBCH 符号 2）。
  - **建议改法**：「固定周期，占 4 个符号 × 240 子载波，PSS/SSS/PBCH 分占其中」。
- 其余为定性论述（宽波束 vs 窄波束、SS-RSRP vs SINR、数 dB~10 dB 覆盖差、高频更严重），无硬数值错误——凭通识成立。

### ch02-q051-ul-alignment-guard-period.md — ⚠️

- **断言**：「30 kHz SCS 下 1 符号 ≈ 35.7 μs（含 CP），可容纳约 **10 km 量级** RTT」
  - **问题**：符号值 ✓（33.33 μs + CP 2.34 μs = 35.68 μs），但 35.7 μs / 6.7 μs/km ≈ **5.3 km**，按文中自己的 GP ≥ RTT 准则应说「约 5 km」，"10 km 量级"偏差 2 倍。
  - **建议改法**：「可容纳约 5 km 量级 RTT」。
- **小瑕**：「往返 2R/3e8×2 = 3.3 μs/km×2」表达式写乱了，但数值 6.7 μs/km 正确（单程 3.3 μs/km × 2）。
- 核对无误：GP ≥ 最大 RTT + 收发转换时间原则、上行→下行保护可 0~1 符号、PRACH 无 TA 时需容纳整个 RTT 窗口、大气波导机理（凭通识）。

### ch02-q054-256qam-mcs-spectral-efficiency.md — ⚠️

- **断言**：「每符号携带 8 bit（64 星座点**翻一倍**的 256 点）」
  - **问题**：64→256 是 **4 倍**（每维间距减半、每维点数翻倍→总点数 ×4），"翻一倍"=128 点=7 bit，数值不对。
  - **建议改法**：「64 点的每维翻倍得 256 点（点距减半），比特数 6→8」。
- 核对无误：
  - 256QAM vs 64QAM 频谱效率 +33%（8/6 ✓）；星座点间距为 64QAM 的一半（间距 ∝ 1/√M ✓）；
  - EVM 要求「256QAM 约 3.5%」——TS 38.101-1 Table 6.4.2.1-1：64QAM 8%、256QAM 3.5% ✓；
  - SINR 阶梯 QPSK <5 / 16QAM 10~12 / 64QAM 18~20 / 256QAM 25~28 dB——量级合理（凭通识）；
  - 上行 256QAM 晚于下行、FR2 需 PTRS、每阶 4~6 dB 代价、命中率百分之几到十几（凭通识）。
