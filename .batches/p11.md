你在为「NR通信面试宝典」实现 P11：自测模式 + PDF 导出。先读 PLAN.md、docs/.vitepress/config.mts、docs/.vitepress/theme/index.ts、docs/.vitepress/components/QuestionBank.vue（学习数据源与样式约定）、scripts/gen-index.mjs。

背景：docs/.vitepress/generated/questions.json 含 300 题元数据 {id,file,url,title,chapter,chapterName,qnum,difficulty,frequency,tags}；题目正文在各章 chNN-qMMM-*.md，固定四个小节：## 一句话答案 / ## 详细展开 / ## 关联考点 / ## 面试追问。

交付：

1. scripts/gen-quiz.mjs（Node ESM）：扫描全部题目 md，生成 docs/.vitepress/generated/quiz.json（包装对象 {count, generatedAt, items:[...]}），items 元素 {id,title,url,chapter,chapterName,difficulty,frequency,sections:{brief,detail,followups}}；三个 section 为对应小节正文 markdown 经 markdown-it 渲染的 HTML 字符串（const MarkdownIt = require('markdown-it')，vitepress 的依赖已提升到 node_modules 根，ESM 里用 createRequire 引入）。两个关键链接处理：
   a) 正文里的相对链接（.md 后缀）必须按「该题自身所在目录」解析为站内绝对路径（以 / 开头、去 .md 后缀、保留中文目录名），因为 HTML 会在任意页面经 v-html 渲染，相对路径会错
   b) 外链与锚点保持原样
2. package.json："docs:index" 追加 && node scripts/gen-quiz.mjs
3. docs/.vitepress/components/SelfTest.vue：
   - 配置面板：章节多选（默认全选）、难度多选（默认全选）、题量 5/10/20 单选，显示符合条件的题数
   - 抽题：按条件无放回随机抽样；答题页逐题：进度 x/N、章节徽标、难度徽标、题干 title；答案区默认遮挡（占位提示「先自己作答，再对照」），点「显示答案」展开 v-html 的 brief/detail/followups；随后「会 ✓ / 不会 ✗」记分进下一题（支持「上一题」回看不改分可选做）
   - 结束页：得分、正确率、错题列表（title + 「查看解析」链接到 url）、「再来一轮」
   - 样式与 QuestionBank 一致（VitePress CSS 变量、深浅色兼容、零第三方库）；随机数只出现在 onMounted 之后（SSR 安全）
4. docs/.vitepress/components/PrintExport.vue：打印导出引导卡——步骤说明（打开 /print 页 → Ctrl+P / ⌘P → 目标打印机选「另存为 PDF」→ 勾选「背景图形」）+「打印 / 导出 PDF」按钮（window.print()）
5. scripts/gen-print.mjs + docs/print.md：gen-print.mjs 把 300 题合并生成 docs/print.md：
   - 结构：frontmatter（title: 打印/导出PDF，outline: [2]）+ 开头一段使用说明 + <PrintExport /> + 每题 `# {chapterName} · {title}` 难度频率标注 + 四小节正文
   - 题目间用 `---` 分隔；每题正文里的相对链接（.md）要改写成相对 docs/ 根的正确相对路径（如 docs/02-物理层/x.md 里的 ./y.md → ./02-物理层/y.md；../06-组网与架构/z.md → ./06-组网与架构/z.md），保留 .md 后缀（VitePress 编译期会重写）；站内绝对链接（/xx 开头）不动
   - 加入 "docs:index" 链；docs/print.md 追加进 .gitignore（生成物）
6. docs/.vitepress/theme/index.ts：全局注册 SelfTest、PrintExport；新建 docs/selftest.md（frontmatter title 自测模式 + 正文 <SelfTest />）
7. docs/.vitepress/config.mts：themeConfig.nav 加「自测」→/selftest、「打印/PDF」→/print；sidebar「开始」组同样追加两项
8. docs/.vitepress/theme/custom.css 增加 @media print：隐藏 sidebar、navbar、VPDocAside（outline）、PrevNextLink、VPFooter 及组件内交互按钮；.vp-doc h1 前分页（break-before: page，首个除外）；正文满宽
9. 验证：npm run docs:index（quiz.json count=300、print.md 生成且含 300 个 `# ` 题目标题）、npm run docs:build 0 死链、dist 含 selftest.html/print.html；用 node 简单断言 quiz.json 中任意 item 的 sections.brief 为非空 HTML 字符串
